# 奶龙劝学 V2.0 人工验收清单

按软件里的实际操作顺序排列，做完一条勾一条。打勾只代表你亲自确认过，不等于我这边测过。

## 一、启动与主界面

1. 双击 `NailongQuanxue.exe`，程序能打开，标题是「奶龙劝学」。
2. 顶部能看到「配置 AI」和「设置」两个按钮，下面一行显示 `AI 接入：未配置 · …`。
3. 首次进入会弹出「奶龙劝学 — 配置视觉 AI」，点「稍后配置」能关掉，主界面正常。
4. 再点一次「配置 AI」，弹窗能再次打开（说明不是一次性死弹窗）。

## 二、倒计时与五分钟休息

5. 设 1 分钟，点「开始计时」，圆环和数字正常倒数。
6. 等归零：出现全屏休息画面，奶龙视频在播且**没有声音**，右下角有「解除限制」。
7. 让休息自然走完（或先跳过这条，后面单独验），确认能回到待机 / 自动进入下一轮。

## 三、摄像头

8. 点「解除限制」→ 对话框里输入「我是废物」，「下一步 · 看示范」才变可点。
9. 看完示范点「开始录制」：
   - 相机指示灯亮，画面有**实时预览**；
   - 进度条走 0 → 12 秒，自动结束；
10. 如果这里显示「Windows 阻止了摄像头访问」，点「打开 Windows 摄像头权限」，在设置页里允许本程序后回来点「重新连接摄像头」。**这是本机已知情况，不是程序坏了。**
11. 录制中按「结束录制」（录满 6 秒后）能正常收尾；不够 6 秒会提示重录。
12. 回到结果页点「重新挑战」，能重新录一段，旧文件不会残留。
13. 全程底部「继续坚持 / 取消」都能退出，退出后相机指示灯熄灭。

## 四、视觉 AI 判定

14. 「配置 AI」里填 Base URL / Key / 模型 / 协议，点「保存配置」，点「测试连接」应能拿到结果（会真的请求你填的服务，产生你自己的费用）。
15. 站着不动录 12 秒 → 应判**未通过**。
16. 只弯腰一次 → 应判**未通过**。
17. 手放肚子 + 两次明显前倾回正 → 应判**通过**，并且「确认投降」按钮才亮起。
18. 断网或填错 Key → 显示中文错误，**不会**判通过。
19. 连续失败多次仍可无限重试。

## 五、投降与档案

20. 判定通过后点「确认投降」→ 当前监督结束（计时归零 / 休息关闭）。
21. 打开「设置 → 投降档案馆」：能看到这条记录，行里有「已保存」录像。
22. 点「查看录像」能播放那段 mp4；点「查看照片」对旧记录仍可用（V1.1 老照片还在）。
23. 把录像目录设成不可写（或塞满配额），再走一次通过 → 仍允许投降，档案里标 `save_failed` / `quota_exceeded`。

## 六、托盘与紧急退出

24. 托盘图标右键 →「紧急退出」→ 确认后立即回到待机，不要求宣言、录像或 AI。
25. 休息界面中同样可从托盘紧急退出。

## 七、旧数据兼容

26. 用 V1.1 留下的 `records.sqlite3` 启动，档案列表能正常显示旧记录（迁移会生成 `.pre-v3.sqlite3` 备份）。
27. 老照片仍能从「投降档案馆」打开。

## 八、放置与退出

28. 开始计时后最小化，程序仍在托盘运行，最后十秒仍会提醒。
29. 关闭主窗口时若正在监督，应最小化到托盘而不是直接退出。
